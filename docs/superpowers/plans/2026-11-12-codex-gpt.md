# GPT mediante Codex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Migrar la demo de examen2Software a GPT mediante una sesión ChatGPT de Codex y conservar sus funciones.

**Architecture:** Un cliente Java invoca Codex CLI como productor de respuestas JSON e implementa el transporte compatible compartido por los adaptadores. Whisper local transcribe WAV antes del planificador. La VM conserva la sesión en su directorio privado y ejecuta procesos sin herramientas del agente ni secretos de la aplicación.

**Tech Stack:** Java 21, Spring Boot, Codex CLI fijado a 0.167.2, GPT-6.1 Sol configurable, Whisper local, Angular, Ubuntu/systemd.

**Spec:** docs/superpowers/specs/2026-11-12-codex-gpt.md

## Global Constraints

- Editar únicamente examen2Software. Mantener los contratos públicos de ClassForge.
- Transport contract `com.classforge.assistant.llm.AssistantChatClient.chat(Map<String,Object>) -> JsonNode`.
- `com.classforge.assistant.codex.CodexCompletionClient` implementa ese contrato y expone `AssistantRuntimeStatus probe(String component)`.
- `CodexApiException(int statusCode, long retryAfterSeconds, String message)` extiende AssistantPlanningException y expone statusCode()/retryAfterSeconds().
- Propiedades codex executable, home, model y request-timeout-millis bajo classforge.assistant.codex.
- Modelo inicial configurable gpt-6.1-sol. CLI 0.167.2. No usar claves API ni endpoints privados de ChatGPT directamente.
- No activar herramientas shell, archivos, MCP, plugins o búsqueda en las solicitudes de inferencia.
- No aplicar cambios UML automáticamente. No exponer logs, tokens o secretos en errores.

## Review Focus

- Salida incompleta, exit distinto de cero o timeout deben fallar sin entregar una propuesta parcial.
- Opcionales de schemas estrictos deben conservar la diferencia entre campo ausente y campo requerido.
- Procesos concurrentes, interrupciones y directorios temporales deben conservar aislamiento.
- El entorno del proceso debe excluir secretos y configuración global del usuario.
- Voz, imagen, herramientas UML y REVIEW deben funcionar desde sus endpoints existentes.
