# GPT mediante la sesión de Codex

El usuario pide sustituir la IA activa por GPT consumiendo su uso de Codex,
sin API key, y desarrollar exclusivamente en examen2Software. Confirma que es
una demo universitaria para el equipo, accesible desde las cuentas del sistema.

La integración ejecutará el CLI oficial de Codex en la VM con una sesión
ChatGPT privada. Cada solicitud tendrá un directorio temporal propio, salida
JSON, plazo máximo y concurrencia acotada. Codex recibirá los datos necesarios
para contestar o proponer UML. Las herramientas de shell, edición, búsqueda y
MCP estarán deshabilitadas. El proceso tendrá un entorno explícito sin los
secretos de MongoDB, JWT, push ni proveedores API.

Texto, ASK, REVIEW, SUMMARY_CURRENT, EDIT y lectura de imágenes usarán GPT.
El catálogo, grounding, referencias, revisión, preview y Apply existentes
seguirán validando las propuestas. El audio se transcribirá con Whisper local
antes de pasar el texto a GPT, porque Codex CLI no proporciona el endpoint STT.

El acceso usa la cuota y disponibilidad de la cuenta ChatGPT/Codex autorizada.
La autenticación privada se conserva fuera de Git, frontend y APK. Los fallos
de autenticación o cuota del proveedor no deben cerrar la sesión de ClassForge.
El repositorio original no se modifica. El despliegue mantiene la URL pública.
